# The Agents Pane's Routing Popups

#2582 redraws the routing policy as Settings' Agents pane, matching the
4 Nov 2026 handoff's frame "Settings Agents" (`_gen/var6.js` `paneAgents6`,
760 wide). The canvas draws one popup per role and leaves several rules
open. This note records who settled each and why.

## Decision

- **The drain-first row is the owner's placement.** PR #2563 added the
  drain-first account after the canvas was drawn. On 4 Nov the owner placed
  it as a third row in the Routing group, a popup over the accepted pools
  saved through the same path as the role popups, rather than in the
  editor alone.
- **Chose Writer to cover three roles** over a popup per task-line role.
  This is the planner's default. The canvas draws Writer and Reviewer only,
  and New Task already reads the specifier, implementer, and remediator as
  one writer (`AgentChoiceDisplay.writerRoles`). When the three orders
  differ, the trigger reads `Differs by role` and the row lists each order,
  so nothing the policy holds is hidden.
- **Chose a menu entry that puts its agent first** over one that replaces
  the order with that agent alone. Also the planner's default. The popup's
  trigger reads the order (`claude-opus, then codex`), so picking an agent
  promotes it and keeps the rest, which is the common change. When the
  roles differed there is no shared rest, so the agent stands alone. Longer
  or finer reorders go through `Change order…`, the existing editor.
- **Chose a one-shot save with a dim refusal line** over opening the editor
  on a refused choice. A choice is a fresh draft checked by the same
  `saveBlocker` the editor's Save uses. If it fails, nothing is sent, no
  draft is left behind, and the reason reads under the group until the
  next choice. Choosing the agent that is already first is refused as "No
  change to save.", which costs less than a separate no-op path.

Revisit when a role needs its own popup apart from the writer group, or
when the routing order grows past what a menu of single agents can set.
