# Timeline Before Current Run

Chose to draw the Timeline's rail first and Current Run under it, over the
4 Nov counter-proposal's order of Current Run first (◆C,
`2026-11-04-2032-task-page-density-decisions.md`, #2611). The owner decided
on 2026-11-05, reviewing #2639.

The rail answers the question most visits to an active task ask, where the
task stands and how it got there, at a glance. Current Run is the detail to
read when the glance is not enough: the live review round and its outcome,
the admission line, and the next schedule, none of which the rail draws.
Before a review exists, Current Run holds little the rail's newest row does
not already say, so drawing it first mostly pushed the Timeline down.

Current Run sits between the rail and the earlier-campaign folds, not after
the whole Timeline section, so the live round never sits under a column of
folded history. ◆C itself stands: both sections stay always open, and only
earlier attempts and earlier campaigns fold. The rejected cost is that the
live review round is now a scroll below the rail instead of the body's first
section; the Runs chip still jumps to it.

Revisit when tasks routinely run past about 15 rail rows, the same trigger
◆C names: a long rail pushes Current Run far down.
