# Probe The Lineup With One Contained Call Per Launch (#2208)

Work unit: #2208. Scope: `daemon/cmd/freesided`, `daemon/internal/ward`,
`daemon/internal/claudeinference`, `daemon/README.md`, and `devlog/`. The
probe copies the writers' setup token and the reviewer's Codex credential
into containers, so this is credential-leak work and the note is mandatory.

## Problem

A lineup can name a model or effort the pinned CLI refuses: a Claude Code
build older than the model needs ("version 2.1.251 or newer is required"),
or a Codex model a ChatGPT-account login can't use. The refusal surfaced
only after a writer or reviewer had launched against a real task.

## Decisions

**Copy each credential into the probe container and have the container
delete it before it stops, over the plan's read-only auth-volume mount and
seeded review snapshot volume.** A mount would make the probe container a
second shape the allowlist must admit, and a seeded volume needs the seeder
and observer lifecycle for one call. The probe container has no mounts at
all. The token is read once from `agent_tree.auth_volume` through the
exporter image, the way the judgment credential reader reads it, and shared
by the writer and judgment calls. The reviewer's credential is derived from
`review.auth_snapshot` by the review provider, so the Codex copy carries no
refresh token.

**Trust nothing the container claims about the deletion.** The only output
path is a rootfs export taken after the container stops itself; the host
reads it into a private temp directory, refuses any export that still holds
the credential stage or `CODEX_HOME`, and removes the directory. An export
without a recorded exit status is refused rather than judged.

**Never refresh a Codex token from the probe.** A refresh spends the
refresh token outside the identity's mutation lease. The probe refuses an
access token that expires within ten minutes and names `freesided
renew-codex`.

**Return raw output from both runners and judge it in one place
(`ward.JudgeLineupProbe`), over a verdict per runner.** The image probe and
the host judgment probe print the same Claude envelope, so one judge keeps
a false pass from hiding in one of two copies. A Claude pass needs a clean
result envelope, a zero exit, and a `modelUsage` key for the requested
model, so a CLI that silently substituted a model fails.

**Refuse while a daemon holds the root's database, and write nothing the
manifest reads.** The record sits beside `composition-manifest.json` as
evidence; a test pins that a launch preflight composes the same bytes with
or without it. A pinned-versus-observed build mismatch is recorded but does
not fail the probe; #2209 owns that check.

**Fix `boundedOutput` in the same PR, as its own commit.** It embedded
`bytes.Buffer`, which promotes `ReadFrom`; `os/exec`'s `io.Copy` prefers
`ReadFrom`, so judgment output was never bounded. The probe's bound test
found it.

## Refute-First Pass

A fresh-context reviewer tried to prove the change wrong:

- **Confirmed, fixed:** the credential and ready copies targeted
  directories under `/var/lib/freeside/lineup-probe`, which the container
  script creates only after the host may already be copying. Both targets
  now sit at the root, as the enrollment seeder's do.
- **Confirmed, fixed:** after an interrupt the loop kept starting calls,
  each binding runtime names into the rig. Remaining calls are now
  recorded as errors without starting.
- **Disproved by a check:** no credential reaches argv, the container
  spec's env, stdout, stderr, the record, or an accepted export; every
  container, network, proxy, and host temp directory is removed on every
  path; model and effort can't break the in-container script's quoting;
  the Codex copy holds no refresh token and the proxy admits no refresh
  host.
- **Allowed by decision:** an `api_key` Codex reviewer would be refused
  as near expiry, but deputy settings refuse `api_key`, so the command
  can't reach it. The export check matches paths, not credential bytes,
  because the export is private and removed. Refusal text is printed
  unescaped because it is the pinned CLI's own output.

Revisit when: the agent allowlist admits a read-only credential mount, or
review launch gains a refresh path that can run outside the daemon.
