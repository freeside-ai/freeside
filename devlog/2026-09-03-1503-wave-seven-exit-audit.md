# Wave Seven Exit Evidence

The adversarial audit at `f8feed7b1d242c2142b9ef37363271a3b781de49`
found that merged units and passing component tests do not establish Wave 7's
decision-surface exit claim. The audit keeps the written close condition as
the standard: an explicit evaluation on #1001 must cover executing actions,
self-contained cards, and the distinction between facts and claims. This is
not a new owner decision or authorization to implement the proposed repairs.

## Durable Identity Survives Vocabulary

Chose preservation of an existing invocation identity over regenerating it
from the current spelling. A valid pending pre-rename discussion can start
under both `elaboration-discussion-` and `specification-discussion-` identities.
Competing completions then fail reconciliation. The frozen upgrade fixture's
completed discussion does not expose this frontier; a pending-state restart
probe does. Decoding both vocabularies is necessary but insufficient for
exactly-once recovery. Follow-up: #1100.

## Authority Must Reach Its Consumer

Chose relationship checks at consumption over treating well-formed returned
objects as authenticated. Client request-generation checks do not establish
that a returned action surface belongs to that card. The measurement reader
likewise accepts an otherwise valid surface with the wrong item binding.
Fresh Signet command acceptance still rejects those substitutions; the gaps
are in presentation and historical measurement. Follow-ups: #1095, #1099.

Recommendation authority must also remain isolated from action authority. A
damaged source row suppresses recommendations on reads but prevents unrelated
item writes. This is a persistence-recovery defect, not a remote command
forgery. Follow-up: #1094.

## Card Truthfulness Includes Placement

Two publication-block causes have no typed lead representation. Separately,
the producer feature changed `publish_block` from creation-immutable to
mutable without the required shared-contract unit. A blind revert could
hide changed canonical hold causes, so an explicit contract adjudication must
precede adding the missing variants. Follow-ups: #1092, #1093.

A first specification card also repeats agent-authored summary text in plain
Context and in the correctly labeled claim section. Having one labeled copy
does not authenticate the other copy. Follow-up: #1098.

## Test Fixtures Must Reach The Claimed Boundary

Chose a real admission-path test over treating retry allocation as admission
evidence. The capability integration test holds dispatch in attended mode;
the selected-manifest admission blocks never execute. No runtime fallback
was demonstrated. Follow-up: #1102.

Comprehension measurements also need actual view events and temporally
qualified opens. An unused drill-down hook produces false zeros, and opening
history after a decision retroactively adds it to rate denominators. These
are measurement defects, not changes to the owner-approved reversal or
instrumented-denominator rules. Follow-ups: #1096, #1097.

## Boundaries Of The Recommendation

The audit does not reopen the decision-surface preimage, add a capability
dimension, implement the refused specification-revision route, or move the
routed-dispute execution trigger. The evidence-metadata clean break remains
an explicit deployment decision. Plain Retry remains absent, which is
different from a rendered control that does nothing; #1101 records that
distinction rather than attributing it to the capability unit.

The remediation order and proposed deferrals live on #1001 and the finding
issues, not here. Revisit this reasoning when an end-to-end exit evaluation
exercises restart frontiers and real card producers on both clients, or when
remediation requires changing one of the settled contracts instead of
enforcing it.
