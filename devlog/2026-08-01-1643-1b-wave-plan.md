## Decisions

- **Chose six waves (3–8) appended to §11's coordination table, mapped to
  the 1B internal exits, over per-exit GitHub sub-milestones** (user,
  2026-08-01), because the milestone field's operative role is the
  scheduled/unscheduled bit (docs/coordination.md), the 1A precedent ran
  108 issues under one milestone across three wave tracking issues, and
  most 1B volume is exit-agnostic deferral backlog that would receive
  arbitrary exit buckets. Wave unit lists live in pinned tracking issues;
  the plan table records shape and sequencing only.
- **Chose to front the Codex review substrate (waves 3–4) rather than run
  it as a late capacity lane** (user, correcting the first draft), because
  #427 — the review stage the useful loop stands on — declares the
  substrate as dependencies. The execution hedge framing was wrong: the
  substrate's front end is critical path for review; only execution
  routing is late by §7's independence sequencing.
- **Chose a dedicated serial review-stage wave (4)** over folding #427
  into wave 3, taking the reviewer-recommended seam: wave 3 otherwise
  combines the largest serialized contract load with the largest runtime
  uncertainty.
- **Amended revision 25's "only the scheduler gates first real-backlog
  use"** to include the §7 review-stage chain. The prior sentence's
  context was the three #420 contracts (scheduler vs. state algebra and
  effect-registry retrofit); revision 25 item 10 itself made review a
  required stage, so the review chain was already on the minimal loop's
  critical path. Named here rather than silently overwritten.
- **Chose Mac-first operator client access** (user): direct install of a
  locally built, personal-team-signed FreesideMac (icon, install/update
  script, real pairing) in wave 3; iOS mid-1B under free provisioning;
  paid Apple Developer Program deferred to Phase 2's APNs. Nothing in 1B
  requires paid membership: APNs is Phase 2 in §11, §5.14 keeps
  correctness independent of push, and the free tier's only iOS cost is
  the 7-day re-provisioning cycle. Personal-team signing on macOS exists
  to keep Keychain ACLs stable across rebuilds, not for Gatekeeper.
