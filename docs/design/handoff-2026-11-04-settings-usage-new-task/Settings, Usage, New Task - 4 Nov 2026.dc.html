Settings, Usage, New Task · 4 Nov 2026
The three decisions of 4 Nov drawn in full on both clients and both grounds: the Settings window and its iPhone list, the Usage page, and the New Task composer. Client-only. Each caption reads platform · surface · rules; the README carries the ledger and the ◆ gate.
What this is
The three decisions of 4 Nov drawn in full: Settings becomes a window on the Mac (⌘,) with a source list and inline controls, and a grouped list on iPhone; Usage is one card per pool with a capacity block per window; New Task is a composer with the agents as chips and no name field. Client-only; no daemon, API or contract change. The README carries the ledger and the ◆ gate.
Unchanged
The design language, tokens, faces and ladders; the list, the task page, every card; the row vocabulary and the recipes R1–R31. New recipes: the capacity block (R32) and the composer chip (R33), both composed from existing tokens.
◆ Owner decisions
1 a General pane (which preferences, if any) · 2 Rename… on the task page, which needs a daemon command the API doesn’t have · 3 the iPhone composer’s presentation (a sheet, as drawn, or the row at the head of the list). The frames draw the default.
